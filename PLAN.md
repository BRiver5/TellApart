# Tell Apart — План реализации

> «Learn the things you mix up.»
> Карточки с вводом ответа, где главное — путаницы: ответ другой карточки
> ловится как mix-up, такие карточки возвращаются рядом, пока не научишься
> их различать.

---

## 0. Архитектурные решения

- Полностью локальное: `expo-sqlite`, без бэкенда и уведомлений; `INTERNET` и
  `POST_NOTIFICATIONS` заблокированы, нужна только вибрация.
- Тема всегда light: «красная ручка» `#B92744` на тетрадной бумаге `#F9F7F3`.
- Все обращения к БД — через мьютекс; ответ — одна транзакция (карточка,
  отзыв, рёбра, веса модели). Прогноз и конфликты — после отрисовки.
- Settings — шторкой на главном, не отдельным экраном (6 экранов).
- Стартовые колоды добавляются только по явному нажатию (контент, не демо-данные).

| Разрешение | Зачем |
|---|---|
| `VIBRATE` | haptics на ответах/тапах, выключается в настройках |

## 1. Движок (`src/lib`)

1. **`match.ts`** — нормализация (регистр, диакритика, артикли), Левенштейн:
   точно / почти (допуск растёт с длиной) / неверно / **перепутал** — если ответ
   ближе к ответу другой карточки колоды, чем к своему.
2. **`memory.ts`** — Half-Life Regression (Settles & Meeder): p = 2^(−Δ/h),
   h = 2^(θ·x + b); признаки — √верных, √промахов, степень путаемости, длина
   ответа. Общие веса θ и сложность карточки b обучаются онлайн SGD на каждом
   ответе (накапливаемое состояние); повторы в той же сессии не учат.
3. **`confusion.ts`** — граф путаниц: ребро растёт на путанице, затухает
   (полураспад 3 недели), ослабевает ×0.6 при верном различении обеих в одной
   сессии; кластеры — система непересекающихся множеств.
4. **`session.ts`** — сессия: точный 0/1-рюкзак по секундам (шаг 5 с), ценность
   = риск забыть × (1 + вес путаемости); путающиеся карточки — контрастными
   блоками подряд, остальные — по колодам по кругу.
5. **`forecast.ts`** — Монте-Карло на 30 дней (24 прогона, фиксированный сид):
   просевшие + новые, ответы до дневного лимита, остальное переносится (долг).
6. **`changes.ts` / `conflicts.ts`** — изменения (минуты, цель, новые в день,
   приостановить) и выходы, проверенные повторным прогнозом с тем же сидом;
   конфликты: долг впереди, узлы путаниц, «пиявки».
7. **`explain.ts`** — разложение периода полураспада по признакам, почему
   карточка в сессии; «чему научилась модель» (множители памяти).
8. **`replay.ts`** — пересборка всего накопленного из журнала (тест сверяет с
   инкрементальным состоянием).
9. **`history.ts`** — по дням, исходы, калибровка (Брайер), серия, полураспады.

## 2. Модель данных

| Таблица | Поля |
|---|---|
| cards | id, deck, front, back, created_at, suspended, correct, wrong, bias, last_at, seconds |
| reviews | id, card_id, at, outcome, answer, confused_with, p (прогноз в момент ответа), ms |
| edges | a, b, w, at |
| meta | settings, model (θ, n), modelVersion |

## 3. Экраны (6)

1. **Home** (Sidebar Categories) — слева колонка колод (All + колоды с
   счётчиками, «+» внизу), справа: сессия (минуты, состав `SessionBar`, старт,
   ссылка на прогноз), баннер конфликта, «Mixed up lately» с Drill, карточки с
   поиском, свайпами (пауза/удалить) и long-press меню; липкие заголовки.
2. **Study** (Focus Single-Card) — одна карточка, ввод ответа, разбор:
   `AnswerDiff` для опечаток, «это ответ для…» при путанице, повтор промахов в
   конце, итог с SuccessBurst; Drill — пара/группа по очереди.
3. **Card detail** — инлайн-правка, `ForgettingCurve` со скрабом, разложение
   полураспада, с кем путается (+ Drill), журнал ответов.
4. **Mix-ups** — `ConfusionWeb` (группы ячейками, тап — фокус), пары с Drill.
5. **Next 30 days** — `LoadChart` (тап по дню), конфликты с выходами,
   what-if (минуты / цель / новые) Now → If, Apply.
6. **Stats** — 8 секций, тап по дню перестраивает исходы и «пропущенные».
